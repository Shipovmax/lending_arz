# Мир спорта

Интернет-магазин на 1С-Битрикс. Шаблон и расширения — в `local/`, страницы — в `site/`, утверждённый прототип — в `design/`.

## Локальный стенд

Скопировать `.env.example` в `.env`, задать свои пароли, выполнить `docker compose up -d`. Сайт: http://localhost:8080. Ядро Битрикса и база хранятся в Docker volumes и не входят в репозиторий. На чистом стенде требуется установка лицензированного Битрикса; миграция реального каталога ещё зависит от выгрузки 1С.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует **демонстрацию утверждённого прототипа**, а не PHP-магазин. В настройках репозитория Pages должен быть выбран источник GitHub Actions. Локальная сборка: `python3 local/tools/build-pages.py`; результат в `dist/`.

Товары и цены демонстрационные, заказ и оплата не отправляются. На Pages нет Битрикса, базы, личных данных покупателей, интеграции 1С и СДЭК. Для рабочего магазина нужен отдельный PHP/MySQL-хостинг.

Состояние реализации и ограничения: `docs/backend-status.md`. Правила разработки: `AGENTS.md`, `CLAUDE.md`.
