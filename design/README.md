# Прототип «Мир спорта» для переноса в Битрикс

Статус: дизайн утверждён Максимом 10.10.2026 как основа для переноса. Контент — заглушки в квадратных скобках, их заменяют данные заказчика и 1С.

Источник дизайна: канвас «Мир спорта: дизайн магазина» в Claude Design. Этот прототип — его чистая вёрстка: адаптивная (от 375 px), без инлайн-стилей оформления, без зависимостей.

## Как открыть

Двойной клик по `index.html` или из папки `design/`:

```bash
python3 -m http.server 8080
```

и открыть http://localhost:8080.

## Структура

- `index.html` — главная
- `catalog.html` — каталог с фильтрами (`?dir=fish`, `?sale=1`)
- `product.html` — карточка товара (цвета и размеры = торговые предложения)
- `cart.html` — корзина и оформление на одной странице, без регистрации
- `info.html` — покупателям: `#order`, `#delivery`, `#payment`, `#return`, `#sizes`, `#contacts`, `#requisites`
- `policy.html` — политика обработки персональных данных (шаблон, проверить юристом)
- `favorites.html` — избранное (хранится в localStorage, личного кабинета нет)
- `404.html` — страница не найдена
- `assets/css/tokens.css` — все цвета, шрифты, размеры, отступы. Менять внешний вид только здесь.
- `assets/css/main.css` — компоненты, адаптив (брейкпоинты 1023 и 767 px)
- `assets/js/main.js` — поведение на чистом JS
- `assets/img/favicon.svg` — временная иконка, до логотипа заказчика
- `_source/` — исходники страниц: общие `partials/` (шапка, подвал, cookie) и `pages/`. Страницы в корне собираются из них.

Править страницы нужно в `_source/`, потом пересобрать:

```bash
python3 design/_source/build.py
```

Проверка в браузере (скриншоты 1280 и 375, ошибки консоли, ключевые сценарии; нужен Playwright):

```bash
python3 design/_source/check.py design /tmp/shots
```

## Перенос в Битрикс

- `_source/partials/header.html` → `header.php` шаблона. Меню — `bitrix:menu`, поиск — `bitrix:search.title`, счётчик корзины — `sale.basket.basket.line`.
- `_source/partials/footer.html` и `cookie.html` → `footer.php`. Контакты и реквизиты — из настроек сайта, не в разметке.
- Каталог — `bitrix:catalog` + `bitrix:catalog.smart.filter`. Счётчики `[N]` в фильтре даёт умный фильтр.
- Карточка товара — `bitrix:catalog.element`. Цвет и размер — торговые предложения, остаток на уровне SKU, `data-left` у размера = остаток.
- Корзина и заказ — `sale.basket.basket` + `sale.order.ajax`: доставка СДЭК (модуль) и самовывоз, оплата онлайн и при получении, гостевой заказ.
- Карта — `bitrix:map.yandex.view`.
- `info.html` и `policy.html` — статические страницы.
- `404.html` → `/404.php` с заголовком статуса 404.
- Сохраняйте `data-*` атрибуты: на них держится `main.js`. Демо-логику (фильтрация карточек на странице, демо-подсказки поиска, демо-итоги корзины) заменяют компоненты Битрикса.
- Шаблоны компонентов копируются в `/local/templates/<шаблон>/components/`, ядро не трогаем (см. `CLAUDE.md`).

## Что заглушки

- Фото товаров, разделов, магазина: серые блоки с подписью «Фото».
- Товары и цены — демо, из `_source/build.py` (`PRODUCTS`).
- Адрес, телефон, часы, email, реквизиты, ссылки на соцсети, бренды, дерево категорий — в `[квадратных скобках]` или с пометкой «пример».
- Логотип текстовый: «МИР СПОРТА» с акцентной чертой.
- Ссылка «Скачать заявление на возврат» и текст оферты — ждут файлы от заказчика.

## Не забыть при запуске

- Аналитику подключать только после «Принять все» в cookie-баннере (ключ `cookie-consent` в localStorage).
- Политику, оферту и условия возврата проверяет юрист.
- Мета-теги `og:image` и настоящая иконка — после логотипа.
