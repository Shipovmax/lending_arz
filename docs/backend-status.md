## Настройки

`local/config/store.php` читает D7 Option модуля `main`:

- `mir_sport_catalog_iblock_id` — инфоблок каталога; fallback `2` только для текущего демостенда.
- `mir_sport_consent_id` — действующее соглашение; fallback `1` для демостенда.
- `mir_sport_price_code` — код типа цены; fallback `BASE`. ID для сортировки определяется автоматически.

Изменения схемы и данных в этом проходе не применялись. Для production нужны подтверждённая схема и отдельная воспроизводимая миграция. Остались демо-коды свойств SKU (`SIZES_SHOES`, `SIZES_CLOTHES`, `COLOR_REF`), справочник цветов и каталог мастера установки.
