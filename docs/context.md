# Контекст проекта «Мир спорта»

Живой документ: кто и что работает, где что лежит, что настроено в базе сервера (в git оно не попадает) и что открыто. Обновляется по ходу работы. Дата последнего обновления в конце файла.

## Что за проект

Интернет-магазин «Мир спорта» (Арзамас) на 1С-Битрикс: спорттовары (одежда, обувь, инвентарь) и товары для рыбалки, около 10 000 позиций. Заказ без регистрации, доставка СДЭК и самовывоз, оплата онлайн или при получении. Остатки и цены из 1С:Управление торговлей 11.5. Бриф и открытые вопросы: `docs/brief.md`. Правила работы: `CLAUDE.md`, `AGENTS.md`.

## Где что работает

| Что | Где |

## Устройство каталога

- Каталог создаёт сама 1С при обмене. Инфоблок товаров 6 «Велосипеды», предложений 7 «Пакет предложений». Демо-инфоблоки 2 и 3 пустые, их товары удалены.
- Витрина читает настройки из `local/config/store.php` (опции модуля `main`): инфоблок каталога, название типа цены, свойства размера и цвета, артикула и бренда, скрытие товаров без наличия, разделы на главной.
- Один тип цены и один склад: редакция Битрикса «Малый бизнес» не разрешает больше. Тип цены называется «Интернет магазин» и совпадает с 1С по идентификатору. В 1С выгружать один тип цены и один склад.
- Меню, навигация, подвал, плитки категорий и бренды строятся из разделов и свойства «Бренд». Пустые разделы скрыты.
- Товары скрываются без наличия, у предложений без наличия и цены тоже. Цена 0 не выводится.
- Контакты и реквизиты: `local/templates/mir_sport/include/*.txt`. Пустой файл или текст в `[...]` на сайте скрывается. Сейчас все файлы пустые, их ждём от заказчика.

## Что настроено в базе сервера (не в git)

После нового импорта скрипт `local/tools/setup-1c-catalog.php` повторяет часть этого сам.

- Опции модуля `main`: `mir_sport_catalog_iblock_id=6`, `mir_sport_price_code`, списки свойств размера и цвета.
- Признаки свойств (показ на странице, выбор предложения, корзина), флаги умного фильтра, фасетный индекс: делает скрипт.
- Модуль `catalog`: детальные картинки из 1С не уменьшаются (`1C_DETAIL_RESIZE=N`), анонс 600×600.
- Тип цены переименован под 1С, один склад «Арзамас» создан импортом.
- Служба обмена: пользователь `exchange_1c`, адрес `/local/exchange/1c.php` (только каталог, заказы закрыты).
- Windows: сон и гибернация от сети отключены, обновления Windows выключены (политика, службы, задачи), Docker Desktop стартует задачей `MirSportDockerDesktop`, контейнеры с `restart: unless-stopped`, туннель перезапускается циклом.
- MySQL: бинарный журнал выключен, буфер 2 ГБ, журнал 1 ГБ. WSL: 10 ГБ памяти, 4 ГБ подкачки (`.wslconfig`).

## Подводные камни (выучено)

- Многострочные блоки PowerShell через stdin не выполняются: скрипты передавать файлом (base64), вывод `docker compose exec` уже UTF-8, вывод самого PowerShell декодировать `iconv -f cp866`.
- Docker Desktop на Windows не умеет тянуть образы по SSH (ошибка учётных данных): собирать образы локально из имеющихся.
- Однофайловые bind-монты при замене файла отстают: после выкладки файлов пересоздать контейнеры `php nginx`.
- Ошибки приёмника Битрикса приходят короткой строкой в ответе (`failure` и текст), в журнале nginx их видно как ответы по 100–180 байт.
- Права проектной проверки: автоматическая проверка блокирует открытие туннелей, `rm -rf` в `sh -c` и вывод учётных данных; такие шаги выполняет пользователь.
